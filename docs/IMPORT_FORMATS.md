# Единый формат взаимодействий

Все арендаторы передают только телефон, email и время взаимодействия. Источник и арендатор определяются выбранным подключением.

| Поле CSV / XLSX / JSON | Содержание |
|---|---|
| `phone` | Телефон; может быть пустым, если есть корректный email |
| `email` | Email; может быть пустым, если есть корректный телефон |
| `time` | Обязательное время ISO 8601 с часовым поясом |

```csv
phone,email,time
+79131234567,visitor@example.invalid,2026-10-30T16:00:00+07:00
,another@example.invalid,2026-10-30T09:30:00Z
```

CSV: UTF-8, BOM допустим, разделитель — запятая, заголовки в первой строке. XLSX: читается активный лист с заголовками в первой строке. Телефоны и даты храните текстом: обычная Excel-дата без часового пояса не принимается. Максимум — 10 MiB и 10 000 записей. Нужен минимум один корректный контакт; некорректное непустое значение отклоняется.

Пустые, повторяющиеся и отсутствующие заголовки перечисляются в ошибке. Регистр значим, крайние пробелы удаляются. Пустой файл или заголовок без записей не считается успешной загрузкой. Лишние поля строки в новом формате не принимаются: ID, имя, сумма и тип покупки не нужны.

Загрузка выполняется в «Источниках данных» и продолжается в фоне. Журнал показывает принятые записи, дубли и отклонения. Исправленный файл можно загрузить повторно: одинаковые нормализованные контакты и время в том же источнике не создают новое взаимодействие.

Успешная обработка файла сама по себе не подтверждает полноту истории. Гарантированный период задаёт администратор либо явно передаёт API арендатора. Его нельзя вычислять из крайних дат строк. Обе границы известны либо обе null; начало раньше окончания; будущий период запрещён. Тип новых событий — `interaction`.

Основной поток — автоматический опрос API по расписанию; файлы подходят для первой истории и дополнений. Контракт API, позиции синхронизации, роли и настройка подключения описаны в [INTEGRATIONS.md](INTEGRATIONS.md).

Старые адаптеры `crm_csv`, `pos_xlsx`, `rest_api` сохранены для совместимости с историей предыдущего формата. Новые арендаторы используют `contacts` и одинаковые поля во всех форматах. API изменения полноты — `PATCH /api/v1/sources/{source_id}/coverage`, только для администратора.
